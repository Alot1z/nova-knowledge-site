Neural option-and-value arbitration

A 481,350-parameter executive that scores which tool should act, given what the machine is doing right now.

PIMO is not a router. A router picks between a fixed list of classes. PIMO scores a scalar per registered option instance against the current state — cache, local model, deterministic function, MCP tool, agent, online endpoint, human, escalation — with no fixed output vocabulary, so a new option is a registration, not a code change.

What follows is measured, not promised. The head-to-head numbers come from EXP-006 and EXP-007; the context addon's numbers come from EXP-009.

Read this before the numbers. Ground truth is an analytic world (world-analytic-v1), not production traffic. PIMO is a ranking model on that world. The honest claim is “beats eleven hand-built and learned baselines on that world, and transfers to option templates it has never seen” — not “will route your agent 40% cheaper”. See About this site.

Calibration is the product, not a metric

Every method in the PIMO head-to-head reports an ECE. Four of them got there by flattening their distribution to temperature 8.00. The two rule systems report confidence 1.0 and cannot be calibrated at all. Only one is both accurate and honest.
