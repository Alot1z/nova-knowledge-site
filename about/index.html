About this site

A knowledge base for NOVA: the design document, 7 articles, and 237 real papers. This page exists so the corpus can be audited instead of trusted.

How the paper corpus was built

  1. Each topic below was issued as an a reference index /works query, twice: once filtered to refereed records (article|proceedings-article) and once unrestricted, because the LLM routing literature is almost entirely preprint.
  2. Records were dropped when they were reviews or editorials, had no DOI-resolvable publisher record, sat in Zenodo as a duplicate deposit, or carried no usable abstract. Dropped records and their reasons are kept in site/data/papers.json.
  3. The selection kept the top 15 most-cited records per topic plus every seed DOI that resolved.
  4. Every page on this site was generated by tools/build_site.py from that JSON. Regenerating with no input change produces byte-identical output.

What is measured and what is not

Accuracy, regret, calibration and the context addon's reduction were all measured on this repository's code. None of it was measured on production traffic, because no production traffic exists yet. In particular: token savings in a real agent are not a measured number here. An option's cost and latency are priors until a caller feeds real telemetry back through record_outcome, record_latency and record_health.

Numbers quoted on this site are copied from the JSON files in experiments/. If a page and an experiment file ever disagree, the experiment file is right.
