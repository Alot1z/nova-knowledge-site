About this site

A knowledge base for NOVA: the design document, 6 articles, and 12 numbered experiment reports. This page exists so the measurements can be audited instead of trusted.

What is published here

  1. Every number on this site is read at build time from a JSON file in experiments/. None is typed into a page by hand, so a page and its data file cannot drift apart.
  2. Every page was generated by tools/build_site.py. Regenerating with no input change produces byte-identical output, and a build gate fails if the committed site is not what the current data produces.
  3. The code that generates this site lives in a private repository. The reports, the articles and the experiment files behind every figure are the public record.

What is measured and what is not

Accuracy, regret, calibration and the context addon's reduction were all measured on this repository's code. None of it was measured on production traffic, because no production traffic exists yet. In particular: token savings in a real agent are not a measured number here. An option's cost and latency are priors until a caller feeds real telemetry back through record_outcome, record_latency and record_health.

Numbers quoted on this site are copied from the JSON files in experiments/. If a page and an experiment file ever disagree, the experiment file is right.
