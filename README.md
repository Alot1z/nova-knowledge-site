# NOVA knowledge site

The published documentation site for [NOVA — Neural Option-and-Value
Arbitration](https://github.com/Alot1z/nova-jev-model), a tiny *learned*
executive that scores dynamically-registered options against the current state
instead of routing through a fixed set of classes.

Live at <https://alot1z.github.io/nova-knowledge-site/>.

## What is here

This repository holds **generated output only**. The site has 269 pages:

- the design document, at `/design/`
- seven long-form articles under `/articles/`
- a research-paper corpus collected from a reference index, indexed by topic under
  `/papers/` and `/topics/`
- a client-side search index at `/search/`

Every number on the site is read at build time from the experiment JSON files in
the model repository. No page can disagree with a measurement, because no page
hard-codes a measurement.

## Where it comes from

The site is generated by `tools/build_site.py` in
[`Alot1z/nova-jev-model`](https://github.com/Alot1z/nova-jev-model) from three
inputs: the design document, the article sources under `site/content/articles/`,
and the collected corpus in `site/data/papers.json`.

**Do not edit files in this repository.** Open a pull request against the model
repository instead; the site is rebuilt from source and the output is committed
here byte-for-byte.

## What the numbers do and do not say

Every accuracy figure is measured against `world-analytic-v1`, the analytic
teacher NOVA was distilled from. That makes them ranking claims, not production
claims. Gate A11 in the design document is still open: an option's cost and
latency are priors until real telemetry lands from a running agent loop.

NOVA does not parse, summarise or compress context. It has no text model. It
scores options. Anything that claims otherwise is describing a different tool.
