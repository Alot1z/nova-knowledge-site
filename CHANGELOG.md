# Changelog

What changed on this site, newest first. Every entry is a commit inthe generating repository; nothing here is written by hand after the fact.

The site is generated by `tools/build_site.py` in `Alot1z/pimo-jev-model`,
which is **private**. What is public is this tree: the reports, the articles,
the design document, and the experiment files every number is read from.

## 2026-10-05 — `2eeff3b`

- **Reference tab.** The five MCP tools, the decision fields, the 30-dimension
  state vector and the 28-dimension option vector are now documented
  publicly. Every field name was read out of the dataclasses and the tool
  signatures rather than written from memory.
- **Light mode.** Every colour became a CSS variable so a
  `prefers-color-scheme` override can repaint the whole page. Six rules
  carried hardcoded hexes and would have stayed dark.
- **Contrast fix.** `--dim` was 4.40:1 on the light background and 3.86:1 on
  the dark panel-2, under the 4.5:1 WCAG AA threshold. It is small meta text
  on every surface. Both palettes now clear AA on all four surfaces, and a
  new gate checks that and can be proven to fail.
- **Favicon.** An SVG, so every browser tab stops requesting a 404.

## 2026-10-04 — `25b1645`

- The reference corpus is no longer published. 237 paper pages, 17 topic
  pages, both nav tabs, the home-page card, the About section documenting the
  collection, and the article about how the corpus was built are all removed. The
  site goes from 283 pages to 26 and now contains a record of PIMO and nothing
  else. The corpus itself is unchanged and still builds — it lives in the
  private repository and on this machine. Two gates now fail the build if any
  of it returns.

## 2026-10-04 — `ee975f9`

- The About landing page added to the search index. It was a nav tab that
  search could not reach.
- `data/` page: every experiment file, linked to its report, with its size.
- `sitemap.xml` (283 URLs) and `robots.txt`, generated from the built tree.
- New gate: a published page missing from the search index fails the build.

## 2026-10-04 — `57e554f`

- Cold-start measurement made the default, so the committed experiment file

## 2026-10-04 — `f4d54c0`

  previously measured 0.8229 — not because of a code change, but because the
  option set is probed from the machine and the skill is now installed, so the
  distribution collapsed to two surfaces. Both numbers are shown with their
