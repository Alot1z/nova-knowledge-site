Limit

This is a hand-built option set, so it measures something the headline accuracy does not: how the learned executive behaves when the options are not the ones it was trained on. The comparison lives in tools/selfhost_audit.py precisely because nova/selfhost.py never imports nova.world &mdash; the self-application must not see the answer key. Escalated decisions are recorded unlabelled, so they cannot leak back into the training set as successes.
