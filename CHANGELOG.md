# Changelog

What changed on this site, newest first. Every entry is a commit in the
generating repository; nothing here is written by hand after the fact.

The site is generated by `tools/build_site.py` in `Alot1z/nova-jev-model`,
which is **private**. What is public is this tree: the reports, the articles,
the paper corpus collected from a reference index, and the experiment files every number
is read from.

## 2026-10-04 — `ee975f9`

- Topics and the About landing page added to the search index. Both were nav
  tabs that search could not reach.
- `data/` page: every experiment file, linked to its report, with its size.
- `sitemap.xml` (283 URLs) and `robots.txt`, generated from the built tree.
- New gate: a published page missing from the search index fails the build.

## 2026-10-04 — `57e554f`

- Cold-start measurement made the default, so the committed experiment file
  cannot lose the field its published page renders.

## 2026-10-04 — `f4d54c0`

- Reports 11 and 12 published: cold start over real stdio JSON-RPC, and the
  ONNX contract (does the exported graph still serve this checkpoint).
- Report 10 corrected. The self-application audit measures 1.0000 where it
  previously measured 0.8229 — not because of a code change, but because the
  option set is probed from the machine and the skill is now installed, so the
  distribution collapsed to two surfaces. Both numbers are shown with their
  provenance.

## 2026-10-04 — `3d3b4b9`

- The MCP decide path stopped paying for capability discovery: 23–30 s down to
  about 4.7 s to first decision.

## 2026-10-04 — `bccef45`, `eafec68`

- Report 10 published: NOVA arbitrating over its own execution surfaces.

## 2026-10-04 — `e64d213`, `5fde77f`

- Reports section added, and a gate that fails the build when an experiment
  file has no report page.

## 2026-10-04 — `1e0998b`

- First publication: README, design document, and this site — 237 real papers
  collected from a reference index across 17 topics.
