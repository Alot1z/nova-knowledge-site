Result

PROCEED. Three independent gates green: (1) tensor-name set equality with the checkpoint, 27/27, zero missing and zero unexpected; (2) numeric parity against a NovaCore rebuilt from artifacts/nova-s.pt through safetensors -- max |HF - NovaCore| = 0.000e+00 on all six heads, agreement 1.0; (3) a real decide() call through the public interface. The package loads out-of-tree from a temp copy with cwd outside the repo and `nova` absent from sys.path. Measured accuracy is unchanged from EXP-003 (test acc 0.9005, regret 0.0029): export is a packaging step, not a modelling step.

Decision

PROCEED. A15 (distributable model) is satisfied. The 1.85 MiB package is committed under dist/nova-s-hf/ and is the only model artifact a consumer needs -- no checkpoint, no dataset, no training run. Caveat recorded: FIXED: the exporter now sorts tensors AND rewrites the safetensors JSON header canonically (fixed-point offset shift, 8-byte padding), and pins newline= for every text artifact. Exporting the same checkpoint twice now yields one sha256, and safetensors/transformers still load the result -- pinned by tests/test_verify_integrity.py.

Limit

Byte-identical export proves the package is faithful to the checkpoint. It does not prove the checkpoint learned anything useful about the world outside the analytic teacher.
