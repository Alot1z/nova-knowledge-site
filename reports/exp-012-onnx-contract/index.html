EXP-005 measured the ONNX path once, at export time, and nothing kept measuring it. Two things can rot without anybody noticing: the checkpoint can be retrained and the graph left stale, so a consumer asking for ONNX is served the old model while every document still calls it NOVA; and the graph can drift numerically from the torch weights it claims to be an export of. This gate checks the recorded checkpoint hash, the per-scenario agreement, and the latency budget.

Limit

The selection-agreement term is gated at 1.0 for fp32 and left ungated for int8, because quantisation is allowed to change a choice &mdash; that is the accuracy cost EXP-005 already measured, and pretending otherwise would make the gate fail on the thing it is supposed to describe. The latency budget is a ratio against the recorded baseline, so a slower machine is not a failure; a 3x regression is. Staleness is detected by hash, which is why the recorded value is only as good as the export that wrote it.
